# Orbit Connect v0.1.18

- Добавлен внутренний системный агент Orbit Connect без сторонних приложений и
  платной Apple Developer Program.
- Режим «Только через доверенный выход» теперь защищает весь исходящий внешний
  трафик Mac через отдельный PF-якорь Orbit Connect.
- При смене сети трафик сначала блокируется, затем фактический публичный IP
  сравнивается с эталоном; совпадение автоматически возвращает доступ.
- Управление контролем выхода выполняется только из Orbit Connect; отдельного
  интерфейса у агента нет.
- Обновление устанавливается поверх версий от `v0.1.14` до `v0.1.17`;
  настройки и привязка сохраняются.
