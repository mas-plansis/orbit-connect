# Orbit Connect v0.1.17

- Исправлен запуск Orbit Connect после обновления.
- Пакет без доверенной Apple-подписи больше не включает системный
  фильтр, который macOS не может запустить с ad-hoc подписью.
- Связь с Orbit, просмотр маршрута, настройки приложений и автоматическое
  обновление сохранены.
- Строгий контроль выхода в этой сборке недоступен до выпуска системного
  расширения с доверенной Apple-подписью; приложение показывает это явно.
- Обновление устанавливается поверх версий от `v0.1.14` до `v0.1.16`;
  настройки и привязка сохраняются.
