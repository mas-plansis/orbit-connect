# Orbit Connect для macOS

Версия приложения: 0.1.17.

Приложение живёт в строке меню macOS и показывает:

- состояние подключения
- конечный адрес
- маршрут устройства

Индикатор на иконке Orbit зелёный при подключении через Orbit, красный при прямом выходе и серый, если состояние пока неизвестно.

Orbit находится автоматически по адресу активного локального шлюза Keenetic на порту 3000. Вводить адрес роутера вручную не нужно. Если три короткие попытки не дали результата, приложение повторяет поиск через 15 и 30 минут, затем через 1, 2, 4, 8, 16 и 24 часа; после этого — раз в сутки. Смена сети или новый запуск приложения начинают поиск заново. Из приложения можно открыть Orbit, KeeneticOS и страницу выбора основного выхода.

Приложение связывается с устройством ключом из Orbit. Данные связи хранятся в системном Keychain. Приложение не читает и не отправляет MAC-адрес.

Orbit узнаёт связанное устройство, даже если его частный Wi-Fi адрес изменился, и автоматически восстанавливает настройки подключения.

Связь можно безопасно удалить из приложения. Одновременно может работать только один экземпляр Orbit Connect.

Автозапуск включён по умолчанию и управляется в настройках приложения. При входе в систему открывается только значок Orbit Connect в строке меню.

Новая версия устанавливается из меню «Проверить обновления». Перед заменой приложения Orbit Connect проверяет контрольную сумму, состав архива и подпись приложения. При ошибке текущая версия сохраняется.

## Только через доверенный выход

Опциональный строгий контроль блокирует входящие и исходящие соединения выбранных
приложений и адресов, пока домашний Orbit не подтвердит включённый статический
выход и ожидаемый конечный адрес. При смене сети доверие сбрасывается сразу.
Проверка продолжает действовать для уже открытых соединений.

Контроль выполняется системным Content Filter. При обычном выходе Connect просит
ввести случайный четырёхзначный код, затем выключает главный контроль и системный
фильтр и только после подтверждения macOS завершает процесс. Настроенные
приложения, режимы и адреса сохраняются. Если фильтр отключить не удалось, выход
отменяется и пользователь получает явную ошибку.

Локальная ad-hoc сборка приложения создаётся командой:

```sh
cd macos/OrbitStatus
./scripts/build-app.sh
```

Ad-hoc пакет не включает Content Filter: macOS не запускает System
Extension с защищёнными entitlement после ad-hoc подписи. Такая сборка
показывает, что сетевой фильтр не установлен, и не сообщает о ложной
активной защите.

Для включения Content Filter нужны доверенная Apple-подпись, разрешённые
Network Extension и System Extension entitlement и оба provisioning profile.
Они передаются одновременно через `CODESIGN_IDENTITY`,
`APP_PROVISIONING_PROFILE` и `SYSTEM_EXTENSION_PROVISIONING_PROFILE`. Скрипт
отклонит неполный набор параметров, чтобы не создать незапускаемый
пакет.
